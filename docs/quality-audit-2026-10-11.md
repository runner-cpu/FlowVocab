# FlowVocab 质量审计记录（2026-10-11）

本次审计覆盖桌面端与 390px 移动端首屏、首次使用引导、首页到词汇训练的答题闭环、设置弹窗、哈希路由、构建产物和 GitHub Pages 发布契约。

## 审计维度

- **产品与信息架构**：首页把学习路线、今日任务、航线地图、成长任务和训练入口串成一条路径；六个模块都保留直接进入入口，避免用户被章节解锁卡死。
- **学习闭环**：词汇答题、正确反馈、继续下一题、连击、每日 XP 和 IndexedDB 持久化均可走通；错误答案会停留在反馈态，避免误触跳题。
- **视觉与品牌**：页面使用夜港主题、单一薄荷主色、局部珊瑚强调色和本地 Outfit 字体；桌面与移动端共享同一套色彩令牌，暗色模式不再依赖局部硬编码。
- **响应式与触控**：390px 视口下顶部导航折叠为底部导航，按钮与输入控件满足 44px 触控目标，图片按视口使用响应式 WebP。
- **可访问性**：跳过链接、焦点可见、路由切换后主内容聚焦、弹窗焦点捕获、`aria-current`、进度语义、图表数据表格和语音反馈状态均已覆盖。
- **状态完整性**：初始化失败、词库下载失败、保存失败、图表加载失败、空内容和模块不可用路线均有可见提示与重试路径。
- **性能**：ECharts、模块页面和词库按需拆分；构建产物的初始 JS 图谱为 367,170 bytes，低于 409,600 bytes 门槛。
- **离线与数据**：Service Worker 只缓存当前 Pages scope 的应用资源，词库分片使用 stale-while-revalidate，学习数据保存在 IndexedDB，并提供导出/恢复和存储失败重试。
- **内容与数据可信度**：生产词库固定为 MIT 许可 ECDICT 快照，5,805 条记录按五级分片，内容校验会检查总量、难度分布和 POS 覆盖率。
- **SEO 与 PWA**：入口包含 canonical、Open Graph、Twitter Card、manifest、favicon、`noscript` 提示和相对路径，适配项目 Pages 子路径。
- **工程与发布**：TypeScript、49 个测试文件、Python 数据测试、lint、PWA 合约、离线合约和包体积门禁均接入验证链；Pages workflow 只上传 `dist/` artifact。

## 本轮修复

1. `#/` 现在与 `/`、`#/home` 一样进入首页，避免从 Pages 根哈希打开时出现误报 404。
2. 初始化加载、初始化失败和路由切换增加明确的屏幕阅读器状态播报。
3. 新手指南和学习设置打开时锁定背景滚动，关闭后恢复原有滚动状态。
4. 设置弹窗支持点击遮罩关闭，继续保留 Escape、焦点捕获和关闭后焦点还原。
5. 应用错误边界使用 assertive alert 语义，页面崩溃时能被辅助技术立即感知。

## 仍需持续观察

- Web Speech API 的识别服务受浏览器和网络策略影响，产品保留打字/选词降级路径。
- 首次词库导入仍会产生一次 IndexedDB 写入成本；后续可继续评估压缩格式和后台导入调度。
- ECharts 图表通过可展开数据表提供无图表替代内容，但还可以在未来增加更细的键盘下钻交互。
