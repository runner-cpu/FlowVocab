## 三、团队原创贡献

- 原创构思：港口点亮星球的产品叙事、错因路由教学闭环、无焦虑激励（连击蓄能替代倒计时）、离线优先的数据策略。
- 系统整合：React + TypeScript + Zustand + Dexie + ECharts 架构搭建，Service Worker 离线方案，CI/CD 与发布契约门禁（`npm run validate`）。
- 内容控制：词库分级、四条学段路线配置、错因分类体系（10 类）与形近词对比卡（48 组）的整理与校验。
- 质量验证：440 项自动化测试与内容校验脚本由团队编写与维护。

## 四、版权与数据合规

- 生成合成内容按国家有关规定及《作品材料提交规范》进行标识【占位：提交前按官方模板逐项确认标识方式】。
- 第三方素材（ECDICT/MIT、Tatoeba/CC-BY 2.0 FR、Outfit 字体/OFL 1.1）均有明确许可并归档许可文件；AI 生成插画不含第三方版权元素。
- 作品不采集用户个人信息：无账号体系、无遥测、语音识别在浏览器本地完成、学习数据仅存本机 IndexedDB。
