## 一、使用状态

☑ 使用人工智能工具。

本作品在三个环节使用了 AI：场景插画生成、编码辅助、视频配音合成。教学内容的选题、结构、判分规则、错因分类和最终成稿由团队完成；AI 产出均经人工筛选、修改或重写后才进入作品。

## 三、两个代表性过程

### 3.1 场景插画

**目的。** 六个训练站需要统一的"暮色海港"场景，纯代码界面缺少空间感，直接用图库又会带来版权和风格不一致的问题。

**输入。** 团队撰写的英文提示词，逐条写明用途、构图、主色、留白安全区和禁止项（无文字、无 logo、无人物正脸、无第三方 IP 元素）。

**产出。** 1536×1024 原图与 4×3 排布的词卡 sprite sheet。

**人工处理。** 每批先看小图筛构图，再看原图查细节；不合格的改提示词重生成。通过后统一色温与描边，按 640 / 1024 宽重采样，词卡按白底裁切、等比缩放居中。最终只保留与整体色调一致的版本。

### 3.2 编码与测试

**目的。** 把时间集中在教学机制和交互设计上，减少重复的样板代码。

**输入。** 项目已有的类型定义、模块划分、失败测试与错误日志。不包含用户数据，也不包含第三方私有代码。

**产出。** 函数级补全、重构建议、测试用例草稿、脚本片段。

**人工处理。** 逐段审查后再合并，不符合项目约定的写法直接删掉。判分规则、五档难度校准、十类错因归因、选项确定性重排、Service Worker 离线契约由团队实现并补测试。所有合并后的代码都要过 `npm run validate`。

## 五、团队原创贡献

作品的核心创意来自团队对背单词经历的复盘：倒计时带来的焦虑、答错后缺少解释、断网即无法学习。这三个问题决定了产品形态，也决定了后续的设计取舍。

团队自主完成的工作：

1. **需求与方案。** 确定"港口点亮星球"的叙事结构、六个训练站的内容边界、四条学段路线的划分方式，以及"错因先于答案""取消倒计时"两条设计原则。
2. **交互与视觉。** 设计首页任务流、答题页信息层级、错因卡结构、结算与星尘灌注流程；制定色彩、排版、圆角与动效令牌，完成深浅色主题和 1920×1080 一屏可答的布局校验。
3. **程序开发。** 实现判分引擎、五档自适应难度、简化版 SM-2 复习调度、十类错因归因、选项顺序去偏、语音识别降级、Service Worker 离线缓存与离线交付包；搭建 566 项自动化测试与发布门禁。
4. **内容制作。** 清洗并分级 5805 条词库；编写 15 个语法节点与 30 道题、8 组句子题、8 段听写与 10 个对话场景、8 个写作任务、3 章阅读与 12 道考点题、48 组形近词对比卡；制定内容校验规则。
5. **测试与优化。** 在 1920×1080 与 1440×900 两种分辨率下逐模块验收，修复答案泄漏、选项位置偏差、主题色不一致等问题；对离线刷新、词库加载失败、语音识别不可用等异常路径做了兜底。

AI 承担的是素材生成与编码提速，不参与教学决策。错因分类体系、难度校准曲线、复习间隔、题目与解析的最终表述均由团队确定；生成图像只用于氛围与题面插图，不替代功能截图；视频中的运行画面全部来自真实操作录屏。

## 六、版权与数据合规

- 第三方数据、字体与开源依赖已在《第三方资源说明》中逐项列明，此处不重复。
- 生成图像不含第三方版权素材输入，不使用他人肖像、声音或商标；提示词与生成记录可核验。
- 作品未使用商业图库、商业字体、商业音乐或影视片段；未使用需要登录的在线服务作为运行时依赖。
- 作品不采集用户个人信息：无账号体系、无遥测；语音识别在浏览器本地完成；学习数据仅保存在本机 IndexedDB。
- 生成合成内容按赛事要求与相关法规作出说明：文档中如实标注工具与用途，视频画面不冒充实拍，生成插画不冒充手绘或摄影。
