## 1. 选题价值与导向（对应指标一）

**问题**：背单词工具普遍存在三个痛点——打卡式倒计时制造时间焦虑；答错只给"正确答案"不给"为什么错"；断网即不可用，学习数据被平台托管。

**对象**：覆盖小学、初高中、进阶、四六级四条学段路线的学习者，路线按课程大纲配置训练模块与内容范围，同一引擎服务不同学段。

**场景**：课后碎片时间自学、通勤等弱网/离线环境、不愿上传个人学习数据的隐私敏感用户。

**价值**：以"港口点亮星球"的叙事把机械记忆变成可累积的成长体验，同时把 SM-2 间隔重复、自适应难度、错因归因三类学习科学机制做成产品闭环。

## 2. 创新性与原创贡献（对应指标二）

1. **错因路由教学闭环**：答错不是简单标红，先按 10 类错因（拼写混淆、词性误用、形近干扰等）归因，再给出对应规则讲解，并自动匹配形近词对比卡（48 组），把每一次错误变成一次针对性教学。
2. **无焦虑激励设计**：取消倒计时，以"5 连击点亮 3 次双倍经验"的蓄能机制替代——答对消耗、答错中断，避免时间压力伤害学习动机；这是针对打卡类产品焦虑设计的反向解法。
3. **离线优先的本地智能**：整站 PWA 化，断网可完整练习；学习数据全部保存在本机 IndexedDB，不上传服务器——同时回应教育公平（弱网环境）与隐私保护两个场景。
4. **叙事化学习路径**：六个训练站（词汇·微光港 / 语法·语法花园 / 句子·桥梁工坊 / 听力·星际电台 / 写作·灵感工作室 / 阅读·故事图书馆）以章节化星图串联，练习产出星尘，星尘灌注星球能量，11 个成长阶段可视可见。

**与既有成果的差异**：与打卡型背词产品相比，差异在错因教学闭环与本地化智能；与普通教育网页相比，差异在完整游戏化循环与离线工程能力。全部交互、算法与代码由团队原创实现，第三方素材见第 7 节授权清单。

## 3. 技术实现与规范（对应指标三）

- **技术路线**：React 18 + TypeScript + Vite，状态层 Zustand，本地持久化 Dexie（IndexedDB），可视化 ECharts（按需引入），Service Worker 提供离线能力。
- **自适应难度引擎**：依据正确率与作答用时在 5 个难度档之间动态校准，维持"跳一跳够得着"的心流区间；练习曲线在成长图谱中可视化。
- **间隔重复调度**：简化版 SM-2——答对间隔翻倍（1/3/7 天起步，上限 30 天），连续 3 次答对记为掌握；"词林"按记忆健康度分档，到期自动排入复习队列。
- **语音陪练**：10 个高频生活场景的问答对话，使用浏览器本地语音识别做关键词与置信度评分，拒绝麦克风权限时自动降级为打字模式，不采集任何音频数据。
- **工程质量**：465 项自动化测试（组件/引擎/store 层 vitest、Service Worker 与发布契约 node --test、内容校验 Python unittest）+ `npm run validate` 一键发布门禁（类型检查、lint、测试、构建、产物体积预算 ≤400KB、内容覆盖率校验）；CI/CD 自动部署 GitHub Pages。
- **数据安全与合规**：无后端、无账号体系、无遥测埋点；学习数据仅存本机浏览器；语音识别由浏览器本地完成；第三方资源均附许可文件（见第 7 节）。应用内「设置 → 关于与许可」直接展示数据流向与素材授权清单，无需查阅仓库。

## 4. 完成度与可验证性（对应指标四）

- **核心功能完整可运行**：六大训练模块全部开放并可结算（星级、星尘、连击、错因卡、语音陪练、复习调度），非概念稿。
- **安装与离线可验证**：作品提供 192 / 512 / maskable 应用图标与 iOS 主屏图标，装到桌面后断网刷新仍可练习；`npm run pack:offline` 可产出含零依赖本地服务器与《启动说明》的离线交付包，评委在无网环境双击即可运行。
- **内容规模**：5805 个词的分级词库（ECDICT），其中 5729 词配有真实语料例句（Tatoeba），内容结构经脚本校验（词性覆盖率 ≥99%）；15 个语法知识点、6 组句子题、8 段听写、8 个写作任务、3 章叙事阅读、10 个语音对话场景（共 51 组问答），按四条学段路线分别划开（首页「知识结构」面板逐格展示开放范围与内容库总量）。
- **可验证方式**：线上 URL 直接访问；`npm run validate` 可复现全部质量门禁；演示视频展示完整操作流；【占位：附核心功能截图与技术架构图】。
- **如实区分**：当前版本为可交付的学生团队原创实现；班级/教师端管理、云同步为后续计划，不在本版申报范围。

## 5. 应用与传播价值（对应指标五）

- **即开即用**：免安装、免注册，浏览器打开即可学习；支持一键安装到桌面/主屏（Chrome / Edge 走安装按钮，iOS 走「分享 → 添加到主屏幕」），安装后以独立窗口运行。
- **离线可用**：适配网络条件有限的学校与家庭场景，服务教育公平。
- **可分享**：链接自带 1200×630 分享预览卡（作品名 + 卖点），转发到群聊或社交平台不会只显示半张插画。
- **可持续迭代**：学段路线、词库、章节内容均为配置化数据，可低成本扩展学段与语种；工程与内容校验脚本保证迭代质量。
- **传播适配**：URL 直达、移动端自适应，适合课堂演示与扫码体验。
