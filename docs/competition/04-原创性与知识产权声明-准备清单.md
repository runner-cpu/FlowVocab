# 原创性与知识产权声明：准备清单

> 数媒赛申报材料草稿 v1（2026-10-12）。《参赛指南》规定报名材料必须包含"原创性与知识产权声明"，并由第一申报单位/学校完成审核与盖章；本清单帮助团队核对声明所需的事实依据，正式签署以官方模板为准。

## 一、需要团队/学校完成的事项

1. 在报名系统（www.cmit.cn）下载官方《原创性与知识产权声明》模板，如实填写并按学校流程盖章。
2. 校内公示：作品经学校资格审核后需按规定进行校内公示，预留时间。
3. 报名截止 **2026-10-23 23:59:59**，系统显示"提交成功"并生成作品编号才算完成报名。

## 三、原创性事实依据（答辩被问随时可出示）

- 版本历史：GitHub 仓库全程提交记录（github.com/runner-cpu/FlowVocab），可展示迭代过程与团队贡献。
- 测试与契约：440 项自动化测试、发布门禁脚本均为团队编写，可作为工程原创性的佐证。
- 内容校验：`scripts/validate-content.mjs` 校验词库结构与覆盖率，内容管线可复现。
- 素材溯源：`docs/ASSET_PROVENANCE.md`、`docs/IMAGE_GENERATION.md` 记录视觉素材的生成与处理链。

## 四、红线自查

- [ ] 无抄袭/剽窃/套作/冒名；核心功能为团队自行开发。
- [ ] 无未披露的 AI 工具使用（对应《人工智能工具使用情况说明》逐项如实勾选）。
- [ ] 无未注明的第三方素材；上表之外若临时新增素材，先补许可再提交。
- [ ] 未以相同或实质相同作品获得过本竞赛往届奖项（首次参赛则无此问题）。
- [ ] 团队人数 ≤5、指导教师 1–2 名且为本校在职教师；报名截止后不变更成员信息。
