## 3. 作品简介

```
《微光港：英语星图》是一款面向小学至四六级学习者的游戏化英语学习 Web 应用。作品把词汇、语法、句子、听力、写作、阅读六个训练模块串成一条港口航线，学习者逐站闯关，答对累积连击与星尘，星尘灌注并点亮自己的成长星球。

主要功能：内置 5805 词分级词库与小学图像词卡；提供语法技能树、长难句拼图、句子排序与改错、听写与语音陪练、章节式叙事阅读；配套自适应难度、间隔复习、错因归因卡与错题回溯、六维雷达与学习热力图。

创新特点：一是错因路由教学闭环，答错后按错因给出规则讲解与形近词对比，错题可一键回到原题重练；二是无焦虑激励，取消倒计时，以连击蓄能替代时间压力；三是离线优先的本地智能，整站断网可玩，学习数据只存本机。

应用价值：免安装、免注册、弱网可用，适配课堂演示、课后自学与隐私敏感场景，助力教育公平；路线与内容均为配置化数据，可低成本扩展学段与语种。
```

## 4. 创意来源

```
选题背景：团队在备考四六级时发现，主流背词产品普遍存在三个问题——打卡倒计时制造时间焦虑；答错只给正确答案，不解释为什么错；断网即不可用，学习数据被平台托管。语言学习真正需要的，是一个持续、低压力、能解释错误的练习环境。

创作动机：我们想做一款「不背单词、打游戏顺便过级」的产品，让学习者在冒险叙事里自然完成高频重复。港口与灯塔的意象来自我们对「微光」的理解：每答对一次就是一点微光，积累起来就能照亮自己的星球。

核心创意：把学习行为映射为可累积的航海叙事——六个训练站对应六类语言能力，通关掉落星尘，星尘灌注星球并推进成长阶段；用错因路由把「错误」从扣分项变成教学内容；用离线优先保证弱网与隐私场景同样可用。
```

## 5. 运行环境

```
软件环境：纯前端 Web 应用，无需安装数据库或后端服务。推荐 Chrome 111+、Edge 111+、Safari 16.4+、Firefox 113+ 等支持 ES2020、Service Worker、IndexedDB 与 color-mix 的现代浏览器。语音跟读需浏览器支持 Web Speech API（Chrome、Edge 体验最佳），不支持时自动降级为选词或打字练习。

硬件环境：普通 PC、笔记本、平板或手机即可，建议 4GB 以上内存、1280×720 以上分辨率；无需独立显卡，麦克风为可选项。

系统平台：Windows 10/11、macOS 11+、Android 8+、iOS 15+。可作为 PWA 安装到桌面或主屏，安装后离线可用。

必要配置：首次访问需联网加载应用与素材（预缓存 113 项、约 3.2MB），进入词汇模块时按需下载分级词库（约 2.2MB）；完成后断网可完整练习。学习数据保存在本机 IndexedDB，清除浏览器数据会同时清除学习记录。另提供离线交付包，可在无网络环境本地启动。
```
