# 微光港：英语星图 —— 运行或使用说明

**作品编号：452953**

**作品形态：** Web 应用（PWA，可安装、可离线）
**在线地址：** https://runner-cpu.github.io/FlowVocab/
**离线包：** `01_作品及成果文件/FlowVocab-offline.zip`

---

## 一、运行条件

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10/11、macOS 12+、Linux（桌面发行版） |
| 浏览器 | Chrome 90+ 或 Edge 90+（推荐）；Firefox、Safari 可运行，语音识别能力因浏览器而异 |
| 屏幕 | 建议 1440×900 及以上；1920×1080 下练习页可一屏显示完整题目 |
| 网络 | 在线访问需网络；安装或首次加载完成后可断网使用 |
| 离线包运行 | 需本机安装 Node.js 14+（仅用于启动本地静态服务，不联网、不安装依赖）；也可用 `python -m http.server` 代替 |

无需注册、无需登录、无需测试账号。

---

## 二、在线使用（推荐）

1. 浏览器打开 https://runner-cpu.github.io/FlowVocab/ 。
2. 首次进入会显示新手指引，可点击关闭；首页即「今日任务 + 航线图」。
3. 建议在地址栏右侧点击「安装」，把应用装到桌面或主屏，之后可独立窗口运行、断网练习。

---

## 三、离线包运行（评审现场无网络时使用）

1. 解压 `FlowVocab-offline.zip`，得到 `FlowVocab-offline` 文件夹。
2. Windows 双击 `启动.bat`；macOS / Linux 在终端执行 `./start.sh`。
   也可手动执行：`node start-server.mjs`。
3. 浏览器打开终端提示的地址 `http://localhost:8080/`。

**注意：** 不要用 `file://` 直接双击 `index.html`。本站是 ES Module + Service Worker 应用，浏览器安全策略要求经 HTTP 访问。若本机没有 Node.js，可在该目录执行 `python -m http.server 8080`。

## 四、五分钟体验动线

| 步骤 | 操作 | 观察点 |
| --- | --- | --- |
| 1 | 首页浏览「今日任务」与航线图 | 六个训练站、星球能量、连续学习天数 |
| 2 | 进入「词汇 · 微光港」，连续作答 | 连击计数、5 连击后的双倍经验提示；答错后出现的错因卡（错因归类 + 规则讲解 + 形近词对比） |
| 3 | 完成一轮，查看结算 | 星级、星尘入账；返回首页把星尘灌注为星球能量 |
| 4 | 打开「成长图谱」 | 六维雷达、学习热力图（点击某天可下钻）、错题回顾（点一条可回到原题重练）、词林到期复习 |
| 5 | 断网后刷新页面 | 练习照常进行；浏览器开发者工具 Application → IndexedDB 可见 `flowvocab-app` 本地数据 |
| 6 | 依次进入语法、句子、听力、写作、阅读 | 语法技能树、长难句拼图、语音陪练、句子排序、章节阅读 |

**语音陪练说明：** 语音识别由浏览器提供，部分浏览器会把音频上传至其厂商服务；不支持识别或拒绝麦克风权限时，可切换到打字输入，评分路径一致。所有识别结果仅用于本次练习，不写入任何服务器。

## 五、数据与隐私

- 无账号体系、无遥测埋点、无上传接口。
- 学习进度、错题、复习计划保存在本机浏览器 IndexedDB（库名 `flowvocab-app`）。
- 清除浏览器站点数据会同时清除学习记录；设置页对此有明确提示，并提供本机数据导出/导入。
- 换设备或换浏览器不会自动同步，这是离线优先设计的直接结果。

## 六、常见问题

| 现象 | 处理方式 |
| --- | --- |
| 打开后页面空白 | 确认使用 Chrome/Edge 90+；确认通过 http 访问而非 `file://` |
| 双击 `启动.bat` 提示未检测到 Node.js | 安装 Node.js 后重试，或改用 `python -m http.server 8080` |
| 端口 8080 被占用 | 设置环境变量后启动，如 `set PORT=8090 && node start-server.mjs` |
| 词汇模块提示词库下载失败 | 检查网络后重试；已缓存的词仍可继续练习 |
| 断网后首次进入某个模块不可用 | 该模块资源尚未缓存；联网进入一次后再断网 |
| 语音识别无反应 | 检查麦克风权限；或切换到打字输入模式 |
| 图表不显示 | 图表为按需加载，弱网下稍等或刷新；每个图表均提供原生数据表替代视图 |

## 七、评审建议路径

若时间有限，建议按以下顺序查看，五分钟内可以覆盖主要创新点：

1. 首页看今日任务与航线图，确认六个训练站的位置；
2. 进词汇，故意答错一题，看错因卡的三段结构（错因、规则、形近词对比）；
3. 连续答对五题，看连击与双倍经验提示，再回首页看星尘灌注；
4. 打开成长图谱，看六维雷达、热力图下钻、错题回到原题；
5. 断网刷新，再答一题，确认离线可用；
6. 最后看语法技能树和阅读章节，了解内容组织方式。
