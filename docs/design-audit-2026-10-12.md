# 前端设计审计与改造方案（2026-10-12）

> 方法：以 `design-taste-frontend`（anti-slop 前端技能）为审计尺子，逐条核对令牌、色彩、图标、版式、动效、可交互状态与可达性。
> 需要先说明技能适用边界：该技能明确写着「不适用于 dashboard / 数据表 / 多步产品界面」。本项目是**游戏化学习产品**（游戏场 + 数据页），
> 因此下文只采用其中**可迁移**的规则（类型与圆角系统、色彩一致性锁、图标统一、可交互状态、动效动机、对比度），
> 并主动放弃其落地页专属规则（hero 高度上限、logo 墙、marquee、bento 单元数等）。

## 设计判读

**Reading this as:** 面向 K12 与大学生自学者的游戏化英语学习产品，保留「港口点亮星球」的探险语汇，但把界面从「多个世代叠加的风格」收敛成一套可维护、可调参的设计系统。

**当前档位测量：** DESIGN_VARIANCE 6 / MOTION_INTENSITY 4 / VISUAL_DENSITY 5。

---

## 一、审计结论（按严重程度排序）

### A. 系统层：令牌只做了一半（最高优先级）

| 指标 | 实测 | 问题 |
| --- | --- | --- |
| 圆角 | 89 处硬编码，仅 4 处用 `var()` | 取值散布在 2/4/5/8/9/10/11/12/13/14/16/17/18/20/22/999，**没有圆角刻度** |
| 字号 | 145 处硬编码，0 处用 `var()` | **24 个不同字号**（9/10/10.5/11/11.5/12/12.5/13/13.5/14/15/15.5/16/17/18/20/22/24/25/26/28/30/34/36/40/42/44），没有类型刻度 |
| 动效时长 | 22 处硬编码（0.1s–0.55s） | 没有时长令牌 |
| 缓动 | **0 个 `cubic-bezier`** | 全部走浏览器默认 `ease`，hover 手感不统一 |
| 断点 | **9 个不同值**（320/330/430/560/640/680/720/760/820/900/1100/1160/1240） | 响应式没有标准刻度，新增样式只能靠猜 |

**影响**：任何一个视觉微调都要在 100+ 处字面量里做点对点修改，且无法保证改全。这是当前最大的结构债。

### B. 色彩：同一个模块有两套颜色（真实的视觉不一致）

`src/types/index.ts` 的 `MODULE_META.color` 是 **Google/Material 品牌色**：
`#5B8DEF` `#34A853`（Google 绿）`#F4B400`（Google 黄）`#EA4335`（Google 红）`#9334E6`（Material 深紫）`#00ACC1`（Material 青）。

`src/data/learningScenes.ts` 的 `tint` 却是另一套：`#1eb7a0` `#3b82f6` `#f28c5c` `#5b7def` `#9b74dd` `#d99843`。

**结果**：词汇模块在雷达图/图例里是蓝 `#5B8DEF`，在场景卡上是青绿 `#1eb7a0`；语法在技能树里是绿 `#34A853`，在场景卡上是蓝 `#3b82f6`。同一模块的视觉身份在不同页面互相矛盾，违反色彩一致性锁。

### C. 图标：三代图标语汇混用

- `TopBar` / `Home` 已用 **Lucide**（合规，项目已有依赖）。
- 但 `MODULE_META.icon` 仍是 emoji（`⚔️🌳🧩🎧🃏📖`），被 `GameHud` 标题、`ModulePage` 上下文条、`Heatmap` 当日明细三处直接渲染。
- 模块内部另有 `🌦️📌💬⚡🔥🏆📖⚔️➡️💡✓×🔒◆` 等符号驱动文案。

**影响**：emoji 在 Windows / macOS / Android 上字形完全不同（同一个 ⚔️ 在三个平台画风迥异），无法随主题变色，读屏会念出「交叉剑」这类无意义名称，且与页面里的 Lucide 图标不属于同一视觉家族。

### D. 可交互状态覆盖不足

- 全站仅 **3 处 `:active`**（`.btn` `.option` `.listen-btn`），但可点元素远超此数：`nav-btn` `track-option` `scene-card` `journey-step` `chapter-stop` `map-node-button` `skill-node` `curriculum-cell` `return` 等均无按下的物理反馈。
- `:focus-visible` 仅 6 处。键盘用户在这些卡点上会失去位置感。

### E. 首页版式：同质化与意图重复

1. **两张地图相邻**：`航线地图`（WorldMap）与 `知识结构 · 学段 × 模块`（CurriculumMap）连续占两个区块，都回答「我该练什么」，读起来是重复导航。
2. **六模块入口是 3 列等宽卡片网格**：被技能明确列为禁止模式（三列等宽 feature cards），而这恰好是全站最重要的功能入口。
3. **场景卡信息过载**：单卡同时承载序号（`01`–`06`）+ 眉标（语境词卡）+ 标题 + 说明 + 进度条 = 5 层，且序号属于「装饰性编号」。
4. 首页大写微标签（eyebrow）实测 5 处，按「每 3 个区块最多 1 个」的尺度略超。

### F. 文案与细节瑕疵

- `CurriculumMap` 里用 `—`（em-dash）作为「不开放」占位符。技能对 em-dash 是零容忍；此处虽属表格惯例，但同一页面既有 `—` 又需要无障碍朗读，改用明文更稳。
- `src/styles/fonts.css` 注释写「见 public/fonts/OFL.txt」，实际许可文件在 `public/licenses/outfit-OFL.txt`，路径已失效（本轮引入的笔误）。
- 正文基准 14px 而最高频字号是 12px/11px（各 27 处），CJK 在 10–11px 下阅读吃力，移动端尤甚。

### G. 已达标项（不需要动，避免过度设计）

- **对比度全部合格**：实测浅色 muted/bg 4.76、muted/card 5.12、ink2/bg 5.97、gold-ink/card 5.81、accent-ink/accent-bg 4.94；深色全部 >9。无 WCAG AA 违规。
- `prefers-reduced-motion` 有全局兜底；`min-h: 100dvh` 用对了；导航高 68px 单行；skipped-link 存在。
- 深浅主题双套令牌齐备，语义分层正确（这一点比多数项目做得好）。

## 二、改造方案（分三层，按风险递增）

### 第 1 层：令牌落地（本轮执行，**零视觉变化**）

新增并在既有 `:root` 内声明四组令牌，然后把**数值完全相等**的字面量替换为令牌引用。因为令牌值 === 原字面量，渲染结果逐像素一致，属于纯重构：

- 圆角刻度：`--r-xs 4 / --r-sm 8 / --r-md 12 / --r-lg 16 / --r-xl 20 / --r-pill 999px`，映射 12/10/14 等到就近档。
- 类型刻度：`--fs-2xs 10 / --fs-xs 11 / --fs-sm 12 / --fs-md 13 / --fs-base 14 / --fs-lg 16 / --fs-xl 20 / --fs-2xl 26 / --fs-display clamp(...)`。
- 动效：`--dur-fast 150ms / --dur 200ms / --dur-slow 400ms` + `--ease-standard cubic-bezier(.16,1,.3,1)` + `--ease-exit`。
- 间距刻度：`--sp-1 4 / --sp-2 6 / --sp-3 8 / --sp-4 12 / --sp-5 16 / --sp-6 24`。

### 第 2 层：一致性修正（本轮执行，可见但不改版式）

1. **模块色彩单一来源**：把 `LEARNING_SCENES[].tint` 收敛为 `MODULE_META[].color` 的派生值，并加测试锁死两者一致；同时把 Google/Material 原厂色替换为品牌调和色（保留辨识度、去掉品牌侵权风险）。
2. **图标统一到 Lucide**：`MODULE_META` 增加 `icon: LucideIcon` 字段取代 emoji 字符串；`GameHud` / `ModulePage` / `Heatmap` 当日明细 / 各模块卡片标题 / 技能树节点标记全部改用 Lucide；保留插画场景图作为图像化认知支持（小学路线仍靠图）。
3. **补齐物理反馈与焦点**：为上述 9 类可点卡点补 `:active` 与 `:focus-visible`。
4. **动效统一缓动**：所有 `transition` 接入 `--ease-standard`，时长保持原值（先统一手感，不改节奏）。
5. **修掉 em-dash 与失效注释路径**。

### 第 3 层：版式重排（**本轮不做，需你先确认**）

以下改动会移动区块位置，可能与你上一轮刚确认的「评委演示动线」冲突，故列为待确认：

- 把 `知识结构·学段×模块` 从首页移到成长图谱页，或降级为首页折叠面板，消除双地图意图重复。
- 六模块入口从 3 列等宽网格改为「1 大 + 5 小」的不对称网格，突出当前路线的主推模块。
- 场景卡去掉装饰性序号，把进度条改为结果态（已完成 ✓ / 进行中百分比 / 未开启）。
- 断点从 9 个收敛到 5 个标准档（640 / 768 / 1024 / 1280 / 1536）。

## 三、验收方式

- `npm run validate` 全绿（类型 / lint / 461 用例 / python / 构建 / 体积预算 / 发布契约 / 内容校验）。
- 新增断言：模块色彩一致性、图标字段为组件而非字符串、em-dash 清零。
- 浏览器实机核对：首页、词汇场、语法技能树、成长图谱，深浅两主题 + 移动窄屏。
