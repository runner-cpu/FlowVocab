# FlowVocab 互动视觉学习升级规格

## 现状审计

- 顶栏原先将图标、中文名和英文名挤在一个文字 Logo 中，品牌识别不够独立。
- 首页任务入口主要依赖纯色卡片和 Emoji，学习模块与真实语境之间缺少视觉记忆钩子。
- 成长图谱已有雷达、热力图和难度流，但时间范围、维度跳转、复习负担没有形成可操作的反馈闭环。
- 只有四六级词库叙事，无法让小学、初高中、进阶和四六级用户看到不同的学习目标。
- 全局视觉曾在深色与浅色规则之间叠加，主题切换入口缺失，移动端也缺少明确的触摸反馈。

## 本轮设计决策

1. 用“开放书页 + 流动路径 + 星点”构成纯图形 FlowVocab Mark，使用 SVG 保持清晰，不在标志中绘制文字。
2. 以冷白、深海蓝、湖绿为基础，使用珊瑚橙、钴蓝、紫罗兰和金色作为场景级辅助色，避免单一色调。
3. 首页增加四条学习路线：小学启蒙、初高中进阶、高中冲刺、四六级备考。路线会影响文案、场景可用性和推荐目标，并用 localStorage 离线保存。
4. 六个学习模块使用同一套插画语言：词汇港、语法花园、句子工坊、星际电台、写作工作室、故事图书馆。图片只负责情境，按钮、文字和学习状态仍由代码渲染。
5. 借鉴 React Bits 的 Spotlight、渐变光晕、Reveal、Animated Number 和轻微 3D 反馈，但不增加新的运行时依赖，并为 `prefers-reduced-motion` 提供降级。
6. 成长图谱增加 7/30/90 天切换、雷达维度入口、复习负担分布与更明确的状态提示；数据继续来自 IndexedDB 与现有 Zustand 状态。
7. 顶栏加入浅色/深色切换，主题通过 `data-theme` 和 CSS tokens 控制，并离线保存用户偏好。

## 验收清单

- [ ] Logo 为纯图形，键盘聚焦与 aria-label 完整。
- [ ] 四条学习路线可切换且刷新后保留。
- [ ] 六张场景卡展示图片、进度、动效，并可进入对应模块。
- [ ] 7/30/90 天可切换，热力图随选择更新。
- [ ] 雷达旁边维度按钮可直接进入训练，图表区域支持点击反馈。
- [ ] 深浅主题在首页、成长图谱、训练场和移动底栏都可读。
- [ ] 390px 移动宽度无横向溢出；减少动效设置生效。
- [ ] `npm run build`、`git diff --check` 通过，在线 GitHub Pages 可加载资源。
