# FlowVocab 多角度质量审查（2026-10-07）

本轮基于 `origin/main` 的最新基线继续审查，不重复已有的分片词库、备份、PWA 和内容授权工作。目标是找出“演示时能用、持续使用或上线后会出错”的问题，并为每类问题留下可重复的验证。

> 后续一轮（微光港主线改造）新增的复审见文末「第二轮：主线改造后的复审」。

## 已处理

### 学习正确性

- 听力挖空位置与答案错位，现由内容测试逐项校验句中词、位置、唯一选项和唯一正确答案。
- 听力第二题继承上一题选择、重开后残留状态、麦克风拒绝后无法继续、离页后晚到回调仍记分，均已修复。
- 句子、听力和阅读重复游玩会重复增加掌握度，现按内容 ID 去重；旧的异常计数在初始化时限制到真实内容上限。
- 同一毫秒结束两轮练习会产生相同会话主键并阻塞保存队列，现按数据库最后 ID 生成单调主键。
- 今日旅程过去答 1 题就显示完成，现按 5/1/3 次真实作答阈值；不可用模块会替换为当前路线可做的语法任务。
- 跨天仍显示昨日 XP/旅程状态、已掌握但到期的词不进入复习提醒，均已修复。

### 数据与离线

- 备份导出现在暂停写队列并在一个只读事务内读取，避免导出半旧半新的快照。
- 词库分片增加并发去重、记录/manifest 校验、安全本地路径、原子写入、缺片恢复、失败重试和真实进度。
- 离线 Service Worker 仅拦截当前应用 scope，不删除同域其他应用缓存；后台更新通过 `waitUntil` 保活。
- 新 Service Worker 等待旧标签页关闭后接管，不会在 30 题任务中途换掉哈希资源。
- 偏好存储被浏览器禁用或配额已满时，主题、路线和指南仍可在当前会话使用。

### 可访问性与体验

- 全局样式合并为一套 token/cascade；补齐深浅主题、表单和深色训练场的对比度。
- CTA 对比度、44px 触控目标、安全区底栏、统一焦点环、skip link、当前页状态和按钮 pressed 状态均已补齐。
- 图表支持深浅主题、reduced-motion、加载/错误/重试/空态，并提供原生详情表作为 Canvas 的可访问替代；热力图跨越午夜时会跟随 Dashboard 的本地日期重新锚定。
- 并发导出/重置使用可计数的写入租约：所有持有者释放前不会恢复写入，避免一个操作在其他破坏性事务中恢复队列。
- Dashboard 难度流在查询前等待练习会话落盘，避免刚结束的一轮不显示。
- IntersectionObserver 缺失时内容不再永久透明；数字动效会取消最新帧并尊重 reduced-motion。
- 听力明确告知语音识别可能由浏览器在线处理，并提供无需麦克风的选词模式；匹配率明确标注不是发音评分。

### 工程与发布

- 测试范围限定在 `src`，不会把仓库内 worktree 的第二份 React/测试误扫进来。
- Vite、Vitest、ECharts 和相关依赖升级到已修复版本；官方 npm audit 结果为 0。
- 首屏预算由“只检查入口文件”改为遍历同步 import 图，当前初始 JS 图为约 359 KB（gzip 123 KB），限制 400 KB；ECharts 保持 Dashboard 懒加载。
- 单一 `npm run validate` 覆盖类型、静态检查、自动化的 Vitest 与 Python 测试、构建、预算、PWA 契约和 5,805 词内容验证。Python 依赖由 `requirements-dev.txt` 固定，干净环境下同样可复现。
- PR 触发只读 CI；Pages artifact 与部署权限仅在 main 推送或手动 main 运行时启用。
- 发布结果：PR #1 的全部检查通过并合并到 main，Pages 工作流成功，线上入口与新构建产物哈希一致。

## 尚未解决的边界

1. Web Speech API 的具体网络/隐私行为由浏览器与地区决定；项目只能提供明确说明和无麦克风替代路径。
2. IndexedDB、Service Worker 和 PWA 更新仍需 iOS Safari/Android Chrome 真机长期矩阵；桌面浏览器不能替代真机配额与休眠行为。
3. 学习雷达是本站内容进度，不是标准化考试能力测量；界面已补充说明，但内容体量仍需继续扩充和实证校准。
4. 本地备份没有云同步；用户清理站点数据前仍需主动导出。
5. 本轮没有引入第三方遥测，因此生产故障依赖用户反馈和 Actions 日志；这是隐私优先的取舍。
6. ECharts 异步 chunk 较大，但不在首屏图中；继续拆分单图表会增加维护成本，需以真实低端设备数据决定。
7. 深度安全扫描工具只报告了图像测试中确定性伪随机数的低危提示；该随机数只生成测试图片，不用于身份、密钥或安全决策。扫描覆盖不等同于完整安全保证。
8. 内容体量差异会让不同路线的“一天”长度不同：小学路线语法只有 1 个节点 2 道题，结算门槛因此设为 2 题并配合短轮次星级封顶；继续扩充路线内容后应重新校准星级与星尘比例。
9. 例句来自 Tatoeba 且只做逐词匹配，未做语义难度分级；5729/5805 词有例句，76 词（拼写变体、绑写形式、含数字句子）暂无，界面会明确提示而不是留空。
10. 语音陪练的对话树是人工编写的 6 个场景，题量有限；扩写时应继续保证关键词必须出现在参考句中。
11. 星尘目前只有「灌注成星球能量」一个用途，能量除影响星球等级外不参与玩法；若要变成真正的经济系统，需要再加入可消费的内容（皮肤/装饰/挑战券）并重新校准掉落。
12. 语法技能树的解锁是「父节点必须先完成」，但路线只开放了部分节点（如 CET 只开 4 个节点）；扩写节点时需保证每个开放节点的父节点也在同一路线内，否则节点会永久锁定。

## 第二轮：主线改造后的复审

主线地图、离线智能与视觉升级上线后，再次按「上线后会怎样」复审，发现并修复了以下问题：

### 星级结算的覆盖率与比例

- **只有词汇章节会结算**：语法、句子、听力、写作、阅读五章即使通关也不给星、不给星尘，航线地图会永远停在第一盏灯。现在六个模块在“一轮/一个节点/一章”结束后都会把本轮成绩交给章节壳。
- **结算门槛与内容体量冲突**：小学路线的语法只有一个节点、两道题，旧的“至少 5 题”门槛会让该路线永远无法点亮语法灯塔。门槛改为 2 题，并对短轮次做星级封顶（1 题全对 1 星、2 题全对 2 星、3 题及以上才可能 3 星），既挡住侥幸又不卡死低内容路线。
- **分次上报被直接丢弃**：模块可能分多次调用 `report`，现在按“本次进入模块的累计量”结算，达到门槛即可点亮。
- **零题上报**：空轮次会被拒绝，未作答的章节不会凭空调亮或掉落星尘；不存在的章节 ID 也会被拒绝。
- **重试与重开的一致**：结算后点“再来一轮”会同时清空本轮累计与已结算标记，不会因为旧状态吞掉下一轮成绩。
- **语音陪练不计入章节**：跟读评分现在按每题一次计入听力章节，与听写模式共用同一套累计逻辑。

### 解锁语义与文案

- 路线未开放的章节原来会显示“前置章节完成后点亮”，指向一个并不存在的前置。现在区分“当前路线未开放”和“前置章节未完成”，并把状态写进无障碍标签。

### 离线与内容呈现

- ECDICT 释义里的字面量 `\n` 会直接渲染成乱码，现统一在展示层规整为中文分号，并保证干扰项按规整后的文本去重。
- 无例句的词原来会渲染空行，现在显式提示“暂未收录例句”，并给英文例句加上 `lang="en"`。
- 新增 `scripts/offline-contract.test.mjs` 固化“只有应用外壳与已下载分片可离线”的边界，并纳入 `check:release`。

### 本轮验证

- `npx vitest run`：49 个文件 / 422 个用例全绿；`npx tsc --noEmit` 无诊断。
- `npm run check:release`：10 个 Node 契约测试（含 Service Worker、首屏预算、离线契约）全通过。
- 浏览器复核：桌面 1440×900 与手机 390×844 的首页、航线地图、听力双标签页、词汇答题与结算屏。

## 第三轮：星级、星尘与成长闭环的复审

第二轮之后继续按方案核对「玩家实际能不能拿到奖励」，发现的问题与处理：

### 星级曾经不可达

- 3 星要求「≥3 题且 ≥90%」，但小学路线的听力只有 2 句、写作只有 2 题、语法只有 2 道题——这些章节再怎么全对也只能拿 2 星，等于给低内容路线设了永远够不到的天花板。现在改为 **≥2 题且 ≥90% 即可 3 星**，并新增连击补偿：一轮内 ≥80% 且最高连击 ≥5 也能拿 3 星（奖励“又快又稳”而不是只看正确率）。
- 一题全对从 1 星提到 2 星，避免单题判分过严。

### 结算口径曾经自相矛盾

- 章节壳先按「累加上报」实现，模块又按「累计快照」上报，两边叠加会把 3 题的作答算成 6 题。现在口径唯一：**模块上报“本次进入模块的累计成绩”，章节壳只接受更完整的那一次（题数更多，或题数相同但答对数更多）**，并在测试里锁死「重复上报不翻倍」「更短的一轮不覆盖更完整的一轮」。
- 星数不再由 store 重新计算，而是由章节壳把带连击信息的星数传入，避免两处算出不同结果。

### 星尘曾经是死资源

- 星尘会随着点亮灯塔不断累积，但全站没有任何消费入口，养成闭环断在最后一环。现在首页航线地图上新增 **星尘工坊**：每 20 星尘灌注 50 星球能量（可在测试里验证批量换算与余数），把「点亮灯塔 → 星球生长」接起来。
- 重玩已通关章节不再重复掉落星尘，结算屏会明确说明“本章星尘已拿满”。

### 提示曾经无代价

- 词汇题的「使用提示」原来免费，等于白送一条线索。现在提示会把该题经验减半（连击、怒气、难度等其他状态不受影响，避免惩罚扩散到后续题目），按钮与提示文本都写明代价。

### 命名与呈现一致性

- 模块元数据里的旧名（词魂战场 / ASMR 听写 / 卡牌对战 / 拆解工坊 / 叙事副本）与航线地图的灯塔名不一致，同一个模块在顶栏、引导、地图、结算里叫法不同。现在统一为 微光港 / 语法花园 / 桥梁工坊 / 星际电台 / 灵感工作室 / 故事图书馆，`desc` 也改成与真实玩法一致的描述。
- 语法技能树只渲染当前路线真正有节点的分支，并提示开放分支数量（之前小学路线会出现 3–4 个空标题）。
- 无例句的词显式提示「暂未收录例句」，而不是留一行空白。
