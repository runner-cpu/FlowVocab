# 参赛就绪度审查 · 2026-10-15

面向赛道：自主选题类（七）智慧教育与科普创作类赛项 · 方向（2）虚拟实验、教育游戏和智能学习工具。

上一轮（`design-audit-2026-10-12.md`）解决的是"设计系统是否自洽"。这一轮换一个提问方式：**如果评审老师此刻打开这个网址，会在哪一步皱眉？** 下面按"评审视角"逐项列问题、给证据、记改动；没做的部分如实留在最后一节。

## 1. 安装身份：能装，但装出来不像一个应用

**问题**：`manifest.webmanifest` 当时只挂了一个 SVG 图标。Android Chrome 能用（支持 SVG 图标），但 **iOS Safari 不读 manifest 里的图标**，只认 `apple-touch-icon` 这个 PNG；缺它的时候"添加到主屏幕"会把页面截图当图标用。Chrome 的自适应图标（maskable）同样需要位图，否则圆形/方形裁切会切掉标志。

**证据**：`index.html` 里没有 `apple-touch-icon`；`public/icons/` 下只有 `flowvocab-icon.svg`。

**改动**：
- 新增 `scripts/build-app-icons.py`：用纯 Python（zlib + struct）从矢量标记的几何确定生成四张 PNG，不依赖 Pillow 也能跑，同一输入必然得到同一字节。
- 产出 `icon-192.png`、`icon-512.png`、`icon-maskable-512.png`（10% 内缩安全区）、`apple-touch-icon.png`（180px）。
- manifest 补齐四个图标条目、`lang`、`categories`；`index.html` 补 `apple-touch-icon` 与 `apple-mobile-web-app-*` 三个 meta。
- 发布门禁新增断言：四张 PNG 必须存在、且 IHDR 尺寸必须是 192 / 512 / 512 / 180（读 PNG 头，不信文件名）。

## 2. 分享预览：链接发出去只看到半张插画

**问题**：`og:image` 指向 `neon-harbor-quest-1280.webp`，尺寸 1280×853（3:2）。社交平台按 **1.91:1** 裁切预览图，结果标题区被切掉，群里转发只能看到中间一段插画，读不出这是什么东西。

**证据**：`index.html` 原 `og:image` 指向场景插画，且没有 `og:image:width/height`。

**改动**：
- 新增 `scripts/build-social-card.py`：1200×630 专用分享卡，左侧渐变压暗 + 中文标题 / 副标题 / 卖点行 / 英文代号。
- `index.html` 补 `og:image:width/height`、`og:locale`、`twitter:image`、`og:site_name`。
- 门禁断言分享卡必须是 1200×630，且 `og:image` 与 `twitter:image` 都指向它、目标文件真实存在。

## 3. 作品名称：同一件作品在界面上有三个名字

**问题**：加载页写「正在唤醒心流词境」，manifest 与文档写「微光港：英语星图」，顶栏 logo 的 title 写 `FlowVocab`。评审对不上号，答辩时容易被问"到底叫什么"。

**证据**：`src/App.tsx` 加载文案、`README.md` 标题、仓库根目录遗留的 `心流词境_项目计划方案.html`。

**改动**：
- 应用内、manifest、分享卡、README、申报文档统一为 **微光港：英语星图（FlowVocab）**。
- 仓库根目录的历史方案 HTML 移入 `docs/archive/2026-09-04-项目计划方案-v2.html`，标题保留原名并标注"历史归档"，让版本演进可追溯而不是被悄悄改写。
- `docs/详细开发设计文档.md` 顶部加名称说明与模块新旧名对照表。

## 4. 导航：进了四个模块，顶栏一条都不亮

**问题**：顶栏只有 首页 / 词汇 / 语法 / 学习数据 四项，但作品有六个模块。进入句子、听力、写作、阅读后，顶栏没有任何一项是 active，用户（和评委）会怀疑"我是不是点错到站外了"。

**证据**：`TopBar.tsx` 的 `NAV` 只列四项，`page === item.key` 判断无法覆盖其余模块。

**改动**：
- 顶栏改为「四个一级入口 + 训练场分组」：句子 / 听力 / 写作 / 阅读 归入 **训练场**，进入这些模块时高亮训练场；点训练场回到首页并把训练模块网格滚进视口。
- 新增两条测试：① 八个可导航页每一个都恰好高亮一个导航项；② 训练场入口能回到首页。

## 5. 授权与隐私：只在仓库里写了，作品里看不到

**问题**：ECDICT / Tatoeba / Outfit 的许可以及"数据不上传"这件事，此前只写在 `THIRD_PARTY_NOTICES.md` 与 README 里。评审不会去翻仓库，作品内没有任何入口；而"原创性与知识产权"恰恰是评分与答辩的常规追问点。

**改动**：
- 新增 `src/data/appInfo.ts` 作为单一数据源（作品名、版本、网址、仓库、三条素材许可、三条隐私说明）。
- 新增 `src/components/settings/AboutSection.tsx`，挂在设置面板底部：**安装到桌面 / 数据与隐私 / 第三方素材许可** 三块，附线上地址与源码仓库外链。
- 门禁断言 `appInfo.ts` 里的 `APP_VERSION` 必须等于 `package.json` 的 version，且三类许可与 `THIRD_PARTY_NOTICES.md` 口径一致、字体许可文件随包存在。

## 6. 安装路径：写了"可安装"，但没告诉人怎么装

**问题**：作品主打"免安装、免注册、可离线"，但浏览器不会主动提示可安装，iOS 更是完全没有安装事件。用户和评委很容易以为它只是个普通网页。

**改动**：
- 新增 `src/hooks/useInstallPrompt.ts`：探测 `beforeinstallprompt` / `appinstalled` / `display-mode: standalone` / iOS `navigator.standalone`，得出三态——已安装 / 可一键安装 / 需手动添加。
- 设置面板据此给出对应文案：可安装时给"安装到本机"按钮；不可安装时给"分享 → 添加到主屏幕"的具体步骤。
- 新增测试断言面板里必须出现主屏安装步骤与音频不上传的说明。

## 7. 顺带修掉的两处一致性问题

- **焦点陷阱漏掉链接**：设置面板的 Tab 回绕只统计 `button` 与 `input`，「关于」区里的外链会被跳过。已把 `a[href]` 纳入回绕范围。
- **测试计数漂移**：申报文档写"440 项自动化测试"，实际已增长。改为不写死数字，改为引用 `npm run validate`。

## 验证方式

```bash
npm run validate      # 类型 + lint + 全部测试 + 构建 + 首屏预算 + 发布契约 + 内容校验
npm run pack:offline  # 生成可双击运行的离线交付包
```
