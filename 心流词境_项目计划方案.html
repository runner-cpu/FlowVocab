01

项目概述与差异化定位 Overview & Positioning

痛点诊断：市面主流产品（百词斩、不背单词、墨墨、扇贝）的差异化集中在"记忆法"，游戏化停留在打卡、积分、皮肤等表层；学习主流程仍是"刷词工具"，缺少即时反馈、动态挑战、情感联结。多邻国的成功证明：让用户坚持的不是内容，而是反馈、目标与情感设计。

目标用户

  • 备考四六级、缺乏持续动力的在校大学生（核心）
  • 词汇/听力/写作单项薄弱、需要专项训练的考生
  • 对游戏化、数据化学习体验有偏好的年轻学习者

核心承诺

  • 每次答题都有"打节拍"式的手感反馈（暴击/连击/怒气）
  • 难度永远"刚好难一点"（动态难度阀门）
  • 六大技能（词/语/句/听/写/读）全部游戏化覆盖
  • 进步可视化：热力图、六维雷达、难度流轨迹

差异化定位

  • 现有产品做"更好的背词工具" → 我们做"值得上瘾的备考游戏"
  • 现有产品游戏化=打卡积分 → 我们游戏化=学习闭环本身
  • 空白地带：写作 AI 批改 + 听力语音实时反馈 + 六维能力可视化
02

设计哲学：心流通道 Flow Channel

一切机制的源头：心流三条件

热情的真正来源不是"内容有趣"，而是心流通道——挑战难度始终略高于当前技能（挑战 ≈ 技能 + 1），且每步操作都有性感的正向反馈。据此制定三条铁律：

  • 铁律一 · 动态挑战：AI 实时监测正确率与反应速度，难度随时调整，让用户始终处在"有点难，但再努把力就能赢"的区间。杜绝"太简单想睡、太难想摔手机"。
  • 铁律二 · 即时反馈：每一次作答立即产生视听反馈——正确且快=暴击（屏幕震动+金币飞溅+合成音效），连续答对=连击升温。反馈延迟不超过 0.3 秒。
  • 铁律三 · 正向延迟满足：所有机制只做"少赚"不做"扣减"。连击中断只是停止生长、少拿资源，植物/星球不会死亡——用正向激励替代惩罚焦虑。

对旧方案的吸收与修正：保留 C 养成（地基）与 B 竞技（引擎），但把核心交互升级为节奏打击式答题并引入动态难度阀门，同时吸收 A/D 的剧情要素（叙事仅作内容包装，控制成本）、E 的听写工坊（补足听力口语刚需）。

核心玩法引擎详设 Core Gameplay Engine

4.1 节奏打击式答题（统一交互范式）

机制触发条件反馈表现数值建议（初值，需实测调参）
基础答对选择正确金币 + 能量 + 音效"叮"经验 +10，金币 +5，能量 +1
暴击正确 且 用时 < 该难度历史中位用时 × 0.7屏幕震动 + 金币飞溅粒子 + 打击音效经验 ×2，金币 ×3
连击 Combo连续答对，计数 +1；答错归零顶部火焰特效随连击升温；连击>10 触发称号"🔥 词汇大师"连击每 +1 追加 +1 能量
怒气值连击 ≥ 5怒气条充满动画 + 全屏渐变触发 30 秒"双倍经验时间"
答错选择错误柔和震动 + 显示正确释义与例句（不扣资源）经验 +2（安慰分），连击归零，错题自动入库

4.2 动态难度阀门（心流核心）

条件动作可视化反馈
近 10 题正确率 > 85%升档：四级核心 → 四级高频 → 六级 → 六级高频 → 考研/超纲；或缩短限时界面边框/主题色升级：绿 → 蓝 → 紫 → 金
近 10 题正确率 60%–85%保持当前档位，微调抽取权重维持当前色阶
近 10 题正确率 < 60%降档：退回上一难度，开启释义提示与例句辅助柔和回落色阶 + "帮你稳一稳"文案
实现要点：① 用滑动窗口（最近 10 题）而非全局统计，响应更快；② 反应速度作为第二信号，正确但超慢也算"吃力"，触发降档倾向；③ 难度切换对用户半透明——只展示色阶与"挑战升级"提示，不暴露算法细节。

4.3 反馈设计规范

  • 视听反馈全链路：Web Audio API 合成音效（无版权风险）+ CSS/Canvas 粒子，反馈延迟 < 0.3s。
  • 所有"失去"都是机会成本而非惩罚：断连 = 少赚能量 = 星球停止生长，永不枯萎死亡。
  • 提供"禅模式"开关：关闭音效/震动的专注选项，兼顾自习室场景。

六大技能模块详设 Six Skill Modules

模块玩法形态游戏化机制考试题型映射数据指标
① 词汇
词魂战场		 节奏打击主战场：左右滑卡（认识/不认识）、四选一点选、听音辨义；词库分四级核心/高频/六级/考研多池 连击暴击动态难度音效反馈 全题型地基（阅读/听力/翻译的词汇基础） 连击纪录、掌握率、平均反应时
② 语法
技能树		 语法点=技能节点（时态/从句/非谓语/虚拟语气…），解语法题=点亮节点；错题自动回到技能树未点亮状态；"拆弹"模式：限时排除错误选项 技能点亮进度树拆弹倒计时 选词填空、写作句法准确性、翻译句式 技能树覆盖率、单点正确率
③ 句子
拆解工坊		 长难句拼图：把句子拆成主干/从句/修饰碎片，拖拽重组还原；翻译对决：中英互译限时对战（先对 AI，后期真人） 拼图进度竞速奖励 翻译（汉译英）、阅读长难句理解 拆解正确率、平均耗时
④ 听力
ASMR 听写		 真题同源原声片段，逐句播放：听一句 → 跟读（语音识别打分）或拼写（听写填空）；波形可视化实时显示音准差异，"唱吧"式反馈 波形反馈音准评分逐句闯关 听力全题型（新闻/长对话/篇章/讲座） 听写正确率、音准得分、回放次数
⑤ 写作
卡牌对战		 收集"高级句型卡"（因果/让步/倒装/强调/插入语…），写作时组牌出招；AI 批改给出结构、词汇、语法三维评分与提升建议 卡牌收集AI 批改组合策略 短文写作、翻译句式升级 卡牌收集率、平均分提升曲线
⑥ 阅读
叙事副本		 真题同源语料改编互动故事，选择影响剧情走向，考点藏在剧情里（推理/主旨/词义）；另有"限时悬赏"模式：限时完成阅读任务链 剧情推进限时悬赏AI 生成语料 阅读全题型（选词填空/匹配/仔细阅读） 剧情完成率、正确率、阅读速度
内容策略：词汇/语法/句子为"主线高频内容"（题库现成、开发成本低）；听力/写作/阅读为"深度内容"（AI 辅助生产语料、真题复用），控制内容消耗速度与成本。

游戏系统详设 Game Systems

养成 · 词汇星球（地基）

  • 连击/答题产出能量 → 喂养星球/能量电池（纯 CSS + 数据可视化，无需画师）
  • 遗忘曲线 = 星球生长节奏：到期未复习则停止生长（不枯萎），复习即恢复生长并加速
  • 目标驱动：每日能量目标达成 → 星球进化阶段 + 今日格子亮金

竞技 · 纪录 PK（引擎）

  • MVP：只和自己比——个人最佳连击、连续达标天数、历史纪录曲线；生成分享海报（Canvas）
  • P3 远期：联机对战、段位（青铜→王者）、ELO 积分、校园战队赛
  • 规避新手劝退：MVP 阶段不引入陌生人负反馈

收集 · 称号皮肤徽章

  • 连击称号：🔥词汇大师（>10 连击）、连击纪录称号
  • 六维成就徽章：语法全点亮、句型卡全收集、听写全对等
  • 星球皮肤：能量电池 → 行星 → 星系外观解锁（CSS 实现）

剧情 · 叙事副本（包装）

  • 章节制，每章绑定一组词汇/语法考点（AI 批量生成语料 + 人工审校）
  • 定位为"内容副本"而非主干：主线仍是六大技能训练
  • 用于拉新与留存钩子：每日开放一章，保持新鲜感

数据智能层 Data & AI Layer

AI 智能体（护城河）

  • 动态难度出题：基于正确率+反应速度实时选档
  • 错题讲解：答错后即时生成针对性解析（先模板，后 LLM）
  • 写作批改：结构/词汇/语法三维评分 + 修改建议
  • 语音评分：听写跟读的音准/流利度评分

遗忘曲线引擎

  • 基于艾宾浩斯升级的间隔重复调度（参考墨墨/扇贝做法）
  • 动态计算每个词/句/点的下次复习时间：熟悉词拉长间隔，薄弱词优先安排
  • 产出直接驱动养成系统"生长/停滞"状态——曲线可视化

六维可视化仪表盘

  • GitHub 风格学习热力图：每日达标格子亮金
  • 六维能力雷达：词 / 语 / 句 / 听 / 写 / 读
  • 难度流轨迹：动态难度变化曲线（心流质量可视化）
  • 连击纪录榜、错题趋势、复习准时率

风险与对策 Risks & Mitigation

风险来源对策
内容消耗快A/D 剧情、听力/阅读语料叙事定位为"副本"非主干；AI 批量生成 + 真题复用 + 人工审校；主线以题库类内容为主
